二维码使用说明

📱 一宠一码 为每只流浪动物生成唯一的二维码标签，包含以下信息：
• 动物基本信息（编号、名称、种类、年龄、性别）
• 芯片编号（用于身份识别）
• TNR处理状态（绝育、疫苗、放归等）
• 全生命周期轨迹记录
• 扫码后可查看动物档案，方便物业、志愿者和公众识别管理
• 建议打印后贴在动物笼舍或放归区域
